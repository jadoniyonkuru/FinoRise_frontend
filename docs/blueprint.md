# **App Name**: FinoRise

## Core Features:

- AI Behavioral Financial Coach: An AI-powered tool that analyzes financial decisions within simulations to provide personalized feedback and behavioral coaching.
- Immersive Scenario Simulations: Interactive branching narratives covering budgeting, savings, and investments where users see the immediate impact of their choices.
- Curated Learning Hub: A modular course system with video lessons and quizzes designed to track financial literacy progression, stored in a PostgreSQL database.
- Gamified XP & Rewards Engine: Comprehensive rewards system that tracks user milestones, XP levels, and allows redemption of partner-sponsored benefits.
- Dynamic Performance Analytics: Advanced visual dashboard displaying financial growth scores, risk profiles, and historical decision-making trends.
- AI Content Recommendation Engine: An intelligent system that uses a tool to suggest specific learning modules based on current performance gaps.
- Admin Control Center: Internal interface for managing learning content, simulation parameters, and monitoring overall user activity trends.

## Style Guidelines:

- The palette follows a sophisticated Dark mode theme inspired by futuristic technology. Background: Deep Onyx (#14111A); Primary: Electric Violet (#8B5CF6) for key interfaces; Accent: Deep Azure (#3B82F6) for secondary emphasis.
- A refined pairing using 'Space Grotesk' for bold, technical headlines and 'Inter' (sans-serif) for high-legibility body text and data tables.
- Custom duotone line icons using a blend of Indigo and Azure to represent financial concepts like assets, risk, and growth.
- Modular, grid-based dashboard layout utilizing frosted glass (glassmorphism) containers with 1px borders to separate core functional modules.
- Subtle Framer Motion micro-interactions, specifically smooth entry fades and progress bar fills, to reinforce the gamification feedback loops.
